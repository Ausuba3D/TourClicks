# Security

## Reporting

Report security issues privately to Ausuba3D@gmail.com.

Do not post employee records, EINs, screenshots containing personal information, exported backups, signing keys, or other sensitive material in a public GitHub issue.

## Signing

TourClicks release signing keys are not stored in this repository.

The retired Janus alpha signing identity is not used for TourClicks public releases.

## Local data

TourClicks stores user records locally. Users are responsible for maintaining backups and protecting exported backup files.
