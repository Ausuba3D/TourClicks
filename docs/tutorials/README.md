# TourClicks tutorials and user guides

These guides help new and regular users configure TourClicks correctly and use its main recordkeeping tools with less guesswork.

## Start here

### 1. Setup and First Use Guide

Read this guide before entering regular work records.

- [PDF guide](TourClicks-Setup-and-First-Use-Guide.pdf)
- [Editable Word guide](TourClicks-Setup-and-First-Use-Guide.docx)

It covers:

- opening or installing TourClicks
- setting the weekly schedule and non-scheduled days
- choosing the pay-period anchor and checking pay-period start and end dates
- entering leave accrual settings and official starting balances
- locating leave values in ePayroll records
- setting up FMLA cases
- entering and checking a first test day
- exporting the first JSON backup

### 2. Daily Use Guide

Use this as the main reference after setup.

- [PDF guide](TourClicks-Daily-Use-Guide.pdf)
- [Editable Word guide](TourClicks-Daily-Use-Guide.docx)

It covers:

- the Today screen and the daily workflow
- BT, OL, IL, and ET entries
- the Timeline and supporting notes or documents
- the Calendar and pay-period review
- the USPS hundredths and makeup-time Calculator
- leave and FMLA tracking
- daily and pay-period Reports
- Android screenshot OCR comparison
- regular JSON backup and restore checks

## File formats

- PDF is recommended for reading, searching, printing, or sharing as a fixed guide.
- DOCX is provided for editing, adding local notes, or producing an updated guide later.
- The repository PDFs are optimized for online viewing. The Word files retain the editable guide content and embedded illustrations.

## Important reminders

- Verify schedules, pay-period dates, leave balances, FMLA information, and clock rings against your own official records.
- TourClicks is local-first. Android and browser data do not automatically synchronize.
- Export JSON backups regularly and keep copies outside the device or browser.
- Do not add real employee records, private screenshots, or exported backups to this public repository.
- TourClicks is independent software and is not affiliated with or endorsed by the United States Postal Service or any labor union.
