# TourClicks Web

TourClicks includes a standalone Progressive Web App built from the same timekeeping core used by the Android application.

## Use

- Records stay local to the browser.
- Android and web data do not synchronize automatically.
- Transfer records with TourClicks JSON backup export/import.
- On iPhone/iPad, open the deployed site in Safari and use Share > Add to Home Screen.
- Export backups regularly because browser storage can be removed by the operating system or browser.

## Platform differences

Automatic bundled ML Kit OCR, persistent Android timer notifications, Android Gallery/Downloads integration, and Android hardware Back integration are Android-only.

The web version still supports screenshot preparation, manual OCR text review, comparisons, Calendar, Timeline, Leave/FMLA, Reports, Settings, timers, and backups.
