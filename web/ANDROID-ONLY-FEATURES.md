# Android-only features

TourClicks shares its core records and calculations across Android and web. Some integrations require Android APIs and are not available in the browser build:

- Automatic bundled ML Kit screenshot OCR
- Persistent timer notification and notification action buttons
- Direct Android Gallery/Downloads integration
- Android hardware Back integration

The browser build provides local storage, offline PWA support after the first successful load, screenshot cropping, manual recognized-text review, value extraction, comparison, reports, timers, backup export/import, and the rest of the core recordkeeping interface.
